One original sentence pitching a ridiculous invention that fixes a tiny everyday annoyance, 127 characters, for make.fun's "One-Sentence Absurd Invention Pitch" bounty, $2.50 in USDC.

> My washing machine sends each sock a farewell card before every spin cycle, which is why only one of each pair ever comes back.

## Run it

```sh
python3 main.py
```

This writes the sentence to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set, for local testing). Deterministic, standard library only, no network.
